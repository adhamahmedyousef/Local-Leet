# Contributing

Open an issue for a bug or submit a focused pull request. Keep changes small and tested.

```sh
npm ci
npm test
python -m unittest discover -s tests -q
```

Do not commit datasets, credentials, generated builds or unrelated files. Pull requests cannot
publish data or deploy Pages. Read [LICENSE](LICENSE) before contributing; forks for pull requests
are permitted, but independent reuse or redistribution requires written permission.
